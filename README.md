# wttm-flip
Flip cards of Welcome To The Moon

## Prérequis

créer un fichier .env dans /front avec les clefs suivantes
```
SECRET_PUSHER_KEY=
FIREBASE_API_KEY=
FIREBASE_AUTH_DOMAIN=
FIREBASE_BDD_URL=
FIREBASE_APP_ID=
FIREBASE_MEASUREMENT_ID=
FIREBASE_STORAGE_BUCKET=
FIREBASE_MESSAGING_SENDER_ID=
```

## Lancement en local
```
docker-compose up -d
```
accessible via :
```
http://localhost:5011
```
